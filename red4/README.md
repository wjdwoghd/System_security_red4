# RED4

시스템 보안 과제로 구현한 파일 암·복호화 프로그램입니다.

AES와 RSA를 이용한 하이브리드 암호화 구조를 구현하고,
파일 암호화 및 복호화 과정을 실습하기 위한 교육용 프로젝트입니다.

> 본 프로젝트는 보안 교육 및 실습 목적으로 제작되었습니다.
> 격리된 실습 환경에서 사용하는 것을 전제로 합니다.

## 주요 기능

- 지정한 디렉터리의 파일 처리
- AES-CTR 기반 파일 암호화 및 복호화
- 파일 앞부분 최대 512KB 암·복호화
- RSA 2048-bit 키쌍 생성
- RSA 공개키를 이용한 AES 키 암호화
- RSA 개인키를 이용한 AES 키 복호화
- 랜섬 노트 생성
- GNOME 환경의 바탕화면 변경 및 복구

## 암호화 구조

프로그램은 AES와 RSA를 조합한 하이브리드 암호화 방식을 사용합니다.

```text
RSA 2048-bit Key Pair
        │
        ├── Public Key
        │       │
        │       ▼
        │   AES Key 암호화
        │
        └── Private Key
                │
                ▼
            AES Key 복호화


Random AES-128 Key + IV
        │
        ▼
AES-CTR
        │
        ▼
